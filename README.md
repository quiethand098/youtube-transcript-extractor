# YouTube Transcript Extractor: batch, timestamps, RAG-ready chunks

Get the transcript of any YouTube video that has captions. Paste video URLs, IDs or a playlist link and receive clean text, optional timestamped segments, and optional chunks sized for vector databases (each chunk carries its start time and a deep link).

## Why use it
- **Batch**: hundreds of videos in one run, plus playlists (first 100 videos).
- **RAG-ready**: set `chunkChars` (for example 1000) and get sentence-aligned chunks with `startSeconds` and a `&t=` link for citations.
- **Language control**: asks for your language first, falls back to auto-generated or any available track.
- **No API key, no cookies, no login.**
- **You pay only for transcripts delivered**: videos without captions are reported in the `ERRORS` key-value record and are not charged.

## Input
| Field | Meaning |
|---|---|
| `videos` | Video URLs, 11-character IDs, youtu.be/shorts links, or playlist URLs |
| `language` | Preferred language code, default `en` |
| `includeSegments` | Add `segments` with start and duration |
| `chunkChars` | 0 = off; otherwise approximate chunk size in characters |

## Output example
```json
{ "videoId": "dQw4w9WgXcQ", "title": "...", "channel": "...", "language": "en", "autoGenerated": false,
  "text": "We're no strangers to love ...", "wordCount": 340,
  "chunks": [{ "index": 0, "startSeconds": 18.6, "link": "https://www.youtube.com/watch?v=dQw4w9WgXcQ&t=18s", "text": "..." }] }
```

## Use cases
LLM and RAG pipelines, video summarization, content repurposing, research datasets, SEO and keyword analysis of video content.

Only public videos with available captions are supported. Respect YouTube's terms and creators' rights when using extracted text.
